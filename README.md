# Python Exercises

## Overview

This repository contains a collection of Python exercises focused on
programming fundamentals, loops, and arrays.

## Contents

-   `Proste programy z pętlami cz. 1.ipynb` --- basic programming
    exercises using loops.
-   `Proste programy z pętlami cz. 2.ipynb` --- additional loop
    exercises.
-   `Tablice jednowymiarowe.ipynb` --- exercises with one-dimensional
    arrays.
-   `Tablice o większej liczbie wymiarów.ipynb` --- exercises with
    multidimensional arrays.

## Topics

-   Python fundamentals
-   Loops
-   One-dimensional arrays
-   Multidimensional arrays
-   Problem solving
-   Jupyter Notebooks

## Purpose

The repository documents my practice with fundamental Python programming
concepts and serves as a collection of programming exercises.

## How to Explore

Open the `.ipynb` files in Jupyter Notebook, JupyterLab, or another
compatible notebook environment.
